# Shane Sunny Kottuppallil — Portfolio

A fast, responsive portfolio for an Associate DevOps / SRE engineer, built with React + Vite and animated with Framer Motion. Deployed on Vercel.

## Sections
Hero · About · Skills · Experience · Projects · Education & Certifications · Achievements · Contact

## Develop
```bash
npm install
npm run dev      # local dev server
npm run build    # production build to /dist
npm run preview  # preview the production build
```

## Deploy (Vercel)
This repo is Vercel-ready (`vercel.json`, Vite framework preset). Connect the GitHub repo in Vercel or run `vercel --prod`.
